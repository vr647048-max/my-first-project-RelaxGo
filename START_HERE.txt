4) RUN WEBSITE LOCALLY / TEST ON COMPUTER + SAME-WIFI PHONE
----------------------------------------------------------
You no longer need to type the server command manually.
Double-click START_SERVER.bat in this folder.

The black window will show the computer IP and the three useful addresses.
Keep that black window open while testing.

On the computer use:
    http://127.0.0.1:8000/

On another device connected to the SAME Wi-Fi use the IP shown by START_SERVER.bat, for example:
    http://192.168.1.37:8000/

OPEN_CUSTOMER.bat opens the customer page on the computer.
OPEN_ADMIN.bat opens the provider dashboard.
OPEN_TRACK.bat opens the tracking page.

IMPORTANT: Mobile GPS requires a secure HTTPS website (or localhost). The local
192.168.x.x test address is useful for checking that the phone can reach the site,
but Chrome may block GPS on that plain HTTP address. The final public site must
be hosted on HTTPS for customer/provider GPS to work reliably on phones.
